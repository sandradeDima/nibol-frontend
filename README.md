# Aplicación web de NIBOL

Este proyecto de [Next.js](https://nextjs.org) se creó con [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Primeros pasos

Inicie el servidor de desarrollo:

```bash
npm run dev
# o
yarn dev
# o
pnpm dev
# o
bun dev
```

Abra [http://localhost:3000](http://localhost:3000) en el navegador para ver la aplicación.

Puede editar la página modificando `app/page.tsx`. La página se actualiza automáticamente al guardar los cambios.

El proyecto usa [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) para optimizar y cargar automáticamente [Geist](https://vercel.com/font), una familia tipográfica nueva de Vercel.
